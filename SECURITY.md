# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Security is paramount to `eval-lake`. Since this platform handles LLM trace data, PII audits, and cryptographic GRC evidence envelopes, we treat all security reports with highest urgency.

If you discover a potential vulnerability:
1. Please **do not** report security issues via public GitHub issues.
2. Email security findings directly to: **security@a2zsoc.com** with the subject line `[SECURITY] eval-lake vulnerability report`.
3. Include detailed steps to reproduce, impact assessment, and proof of concept if applicable.
4. You will receive an initial response within 24 hours acknowledging receipt and defining remediation timelines.
